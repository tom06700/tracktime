# Nitrate — trois états vides Séries
Aperçu autonome pour Brave, sans modification de Flutter.
Éventail : affiches déployées, composition centrée.
Premier rôle : affiche centrale, navigation au clic, clavier ou glissement.
Collection prend vie : texte d’abord, rail en cascade à faire défiler.
Sources locales : atlas collection_posters.png, wordmark, Inter, Lucide du projet.
Boucle sept secondes, ralenti, rejouer et prefers-reduced-motion.
Explorer permet recherche, ajout/retrait éphémère et retour à Séries.
Titres fictifs. Aucune écriture dans la vraie collection ni requête externe.
Lancement : python3 -m http.server 8767 --bind 127.0.0.1
